# Dysarthric Speech Recognition

Exploratory research on automatic speech recognition (ASR) for dysarthric speech, conducted under Prof. Mariya Celin at Sai University, Chennai.

## Overview

Dysarthria is a motor speech disorder that affects articulation, making speech harder for standard ASR systems to recognize accurately. This project explores approaches to improve recognition performance on dysarthric speech, with the broader goal of making assistive speech technology more accessible.

## Dataset

- **UA-Speech corpus** — a database of dysarthric and control (non-dysarthric) speech recordings, widely used for benchmarking dysarthric ASR research.

## Approaches Explored

This is an active research project; the methods below are being explored and compared, not a single fixed pipeline:

- **Classical feature extraction**: MFCC (Mel-Frequency Cepstral Coefficients) and GFCC (Gammatone Frequency Cepstral Coefficients)
- **Self-supervised representation learning**: HuBERT-based embeddings

## Status

🚧 Work in progress — actively comparing classical feature-based and self-supervised approaches. Results and methodology are being prepared for submission to IEEE.
